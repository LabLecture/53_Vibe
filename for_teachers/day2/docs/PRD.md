# PRD — cs.AI 신규 논문 주간 알림

## 1. 문제
cs.AI 분야 신규 논문이 매일 쏟아져 놓치기 쉽다.
수작업으로 매번 확인하기엔 비효율적이다.
정기적으로 걸러진 최신 소식만 받고 싶다.

## 2. 사용자
cs.AI 최신 연구를 추적하는 개인 사용자(연구자/개발자).
매주 한 번, 주 시작 시점에 확인하고 싶어 함.
Discord를 주 커뮤니케이션 채널로 사용.

## 3. 핵심 기능
매주 월요일 정해진 시각에 자동 실행.
arXiv cs.AI 카테고리에서 최근 7일 이내 신규 등록 논문만 수집.
수집 결과를 Discord 채널로 전송.

## 4. 비기능 요구
스케줄 실패/누락 시 재시도 또는 알림 필요.
중복 논문(이미 보낸 것) 재전송 방지.
Discord API 요청 실패 시 에러 로깅.

## 5. 성공 지표
매주 월요일 알림 100% 정시 발송률.
7일 윈도우 기준 신규 논문 누락 0건.
중복 전송 0건.
